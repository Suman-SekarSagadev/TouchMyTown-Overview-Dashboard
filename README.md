# TouchMyTown Sales Dashboard

## Overview
Interactive Power BI dashboard for analyzing sales performance across cities, products, customers, and payment methods.

## Features
- Sales Trends Analysis
- Top Products Performance
- City-wise Revenue Distribution
- Customer Metrics
- Payment Mode Analysis
- Geographic Sales Map

## Tools Used
- Power BI
- DAX
- Power Query
- Excel
